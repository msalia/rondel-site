# Rondel Site

Showcase and documentation site for the [Rondel](https://github.com/msalia/rondel) circular barcode library.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- `@msalia/rondel` installed from GitHub

## Development

```bash
npm run dev    # Start dev server on :3000
npm run build  # Production build
```
